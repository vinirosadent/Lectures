Duplicating Materials
1- The cast on which the wax pattern of the metal framework is to be
formed must be made from refractory investment because it must
withstand the casting temperature required for gold or base metal
alloys
2- The original cast is needed for checking the accuracy of the metal
framework and for processing the denture base portion of the partial
denture
Types
Type I (Thermoreversible)
Class I  - Hydrocolloid
Class II - Non-aqueous organic eg polyvinylchoride
Type II (Non-reversible)
Class I   - Hydrocolloid
Class II - Non-aqueous organic eg silicones
Class I
Hydrocolloids
• Similar to the impression material except that its water content is
  higher.
• Economical to use but should not be used too many times because of
  hydrolysis and contamination.
• Dimensional change occurs on storage.
• Most commonly used.
Class II
Non-aqueous organic eg Polyvinvylchoride
• High strength properties
• High chemical stability and therefore permits a large number of
  duplications.
• Equipment needed to heat up the material.
Class I
Hydrocolloid
• Easy to use
• Dimensional accuracy on storage is not good.
Class II
Non-aqueous organic eg silicones
• It is non-reversible
• The material is expensive.
• More than one cast may be made.
